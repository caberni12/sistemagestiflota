CAMBIO PRINCIPAL - COMBUSTIBLE
El formulario de Contexto operativo / Fecha / Tipo / Litros / Precio / Kilometraje / Boleta / Pago / Observaciones ya no ocupa el área principal del mapa.

Flujo:
1. Abrir Informar carga.
2. El mapa y estaciones CNE ocupan el espacio principal.
3. Seleccionar una estación.
4. Pulsar “Completar datos de carga”.
5. Se abre un submodal con los datos finales de la carga.
6. Guardar carga.

Se conserva:
- Región / Comuna / Empresa-Marca CNE.
- Precios 93 / 95 / 97 / Diésel.
- Logos locales de estaciones en el mapa.
- GPS y navegación.
- Kilometraje manual solo Administración/Gerencia; demás perfiles por cámara/NEXO IA.
- Asociación a vehículo, conductor, ruta/operación y empresa activa.

API recomendada: flotas-api 4.5.52 con renovación automática de token CNE.
