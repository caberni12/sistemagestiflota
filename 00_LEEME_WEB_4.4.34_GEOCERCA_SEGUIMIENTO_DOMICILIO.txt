E-FLEET MANAGEMENT SYSTEM · WEB 4.4.35 · ASSETS UNIFICADOS

OBJETIVO
- Un solo CSS fisico para toda la Web: efleet.css
- Un solo JS fisico para toda la Web: efleet.js
- Los HTML solo llaman esos dos assets.
- Se mantiene la logica funcional de Web 4.4.32 / R8.2.92.

ARQUITECTURA
- efleet.css contiene base, responsive, paleta, Login, Menu principal, Geo Local, Geocerca, Alertas/Notificaciones y Reportes.
- Las reglas que antes eran exclusivas de una pantalla quedaron aisladas por clase de pagina en <html> para evitar contaminacion visual entre modulos.
- efleet.js selecciona la logica correcta segun el HTML actual y conserva las versiones de Geo Common usadas por cada pagina.
- efleet.js tambien actua como Service Worker cuando el navegador lo ejecuta en contexto worker; por eso no hace falta un segundo archivo sw-*.js.
- JSZip ya estaba embebido dentro del modulo principal; el publicador Android tambien se incorpora al bundle unico.

REGLA PARA VERSIONES FUTURAS
No agregar CSS o JS nuevos a los HTML. Toda correccion Web debe entrar en efleet.css o efleet.js.
Los HTML deben conservar exclusivamente:
  <link rel="stylesheet" href="efleet.css?v=4.4.35">
  <script src="efleet.js?v=4.4.35"></script>

BASE FUNCIONAL
- Geo Local / Check-in / disponibilidad Ruta de R8.2.92 conservados.
- Radio azul de Geocerca conservado.
- Autoajuste para notebooks y pantallas pequenas conservado.
- Configuracion solo autorizada desde cPanel conservada.
- Aislamiento multiempresa no se modifica en esta version Web.


NUEVO 4.4.35
- Geocerca permite filtrar/seguir una persona directamente encima del mapa.
- Al filtrar: muestra solo hogar + GPS de esa persona.
- Traza línea azul GPS ↔ domicilio.
- Muestra distancia real en metros/km y radio configurado.
- El hogar queda marcado de forma independiente y el círculo azul permanece visible.
- Si GPS no es reciente, la línea se muestra como última ubicación conocida.
